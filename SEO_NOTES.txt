SEO changes (29 Oct 2026)
=========================
New file:   seo_content.py  -> unique text, tips, extra FAQ and a Hindi section for every tool page + home.
            Edit this file to change page copy. Change SITE_UPDATED when you change content (sitemap lastmod).
            templates/404.html -> noindex "page not found" page.
Changed:    app.py, templates/base.html, templates/tool_base.html, templates/home.html

After deploying
1. Render env vars: SITE_URL=https://maxdownloader.in  and  CONTACT_EMAIL=<your real email>
   (without CONTACT_EMAIL the Contact/Privacy/DMCA pages show your-email@example.com).
2. Search Console: open Sitemaps and submit sitemap.xml again. Then use URL Inspection > Request indexing
   on the home page and the 4 main tool pages.
3. Wait 2-4 weeks, then check Performance > Queries and tune titles for queries that get impressions but no clicks.

Backend fixes (29 Oct 2026)
===========================
- instagram_core.py: a Reel / TV link no longer ends as a JPG cover picture. If a method only finds the cover,
  the next method is tried; if none finds the video, an error is shown instead of a JPG.
- pinterest_core.py: one quick retry on timeouts and temporary Pinterest errors. If the pin page is blocked,
  Pinterest's JSON endpoint and yt-dlp are tried before giving up. A video pin is never saved as its cover photo.
- app.py: /api/cookie-check can now test every downloader.

Find out which downloader is failing on the live server
  https://maxdownloader.in/api/cookie-check?key=<HEALTH_KEY>&all=1&fresh=1
  (set the env var HEALTH_KEY on Render first, any long random text). It shows YouTube, Instagram, Pinterest and
  Twitter separately, the reason for each failure, and the yt-dlp version. ?only=pinterest tests one.
Common causes: Instagram/YouTube/Pinterest block cloud server IPs. See README for cookies (YT_COOKIES_FILE,
IG_COOKIES_FILE) and the IG_PROXY option. Redeploying also installs the newest yt-dlp, which fixes many YouTube errors.
